# Game Room: brand kit

## The name
**GAME ROOM**, always one idea. Written `Game Room` in sentences and `GAME ROOM` in headings and graphics.
Party mode is called **Fun Day**, after the night it was built for. The quiz library is the **Quiz Shelf**.

Handles to grab (same everywhere): `@gameroom.exe` (first choice), then `@playgameroom` or `@gameroom.class`.

## One-liners
- **Tagline:** Hard questions. Real games. One room.
- **For students:** Small games about how things actually work.
- **For teachers:** Run a whole class party from one projector. Everyone plays on their phone.
- **For the quiz crowd:** Quizzes that tell you why.
- **Ten-second pitch:** Game Room is a free arcade of real games and deep quizzes (AP Bio, AP Stats, bioinformatics, comparative religion). Teachers can buy a lifetime code to run it as a class party on the projector.

## Voice
Plain, funny, direct. A good teacher talking to students they like.
- Short sentences. Concrete nouns. Numbers over adjectives.
- Say what happens: "Every guy walks to the answer they picked."
- Brag with specifics: "32 questions. Every one explains itself."
- **Never:** wellness or mindfulness words (journey, curiosity, unlock your potential, let go, breathe), hype words (revolutionary, game-changing), emoji walls, "edutainment".

| Write this | Not this |
|---|---|
| The last question is a boss. It counts double. | Elevate your learning journey with gamified assessments! |
| You are the bird. Eat the moths you can see. | An immersive exploration of natural selection. |
| One code. Every device. For life. | Unlock lifetime premium access today! |

## Look
Win95 meets Swiss poster: rectangular windows, maroon title bars, silver bevels, a grid floor, giant bold type, pixel icons.
No gradients, glow, rounded corners or emoji. **No blue and no green, anywhere.**

| Token | Hex | Use |
|---|---|---|
| Desk (maroon-black) | `#4a1d2c` | Backgrounds |
| Title bar (maroon) | `#7a0f1f` | Window bars, accents, icon accent |
| Silver | `#c0c0c0` | Windows, buttons |
| Red | `#c0001a` | Answer A |
| Yellow | `#ffd400` | Answer B, highlights, "correct" |
| Purple | `#7a2d86` | Answer C |
| Ink | `#000000` / `#222222` | Text, answer D |
| White | `#ffffff` | Headlines on the desk |

**Type:** headlines in Arial Black (or Helvetica Neue Black), tight tracking, ALL CAPS, stacked two words per line
("GAME / ROOM", "QUIZ / SHELF", "FUN / DAY"). Body in Tahoma. Numbers and code in Courier New.

**Icons:** the ASCII pixel set in `engine/icons.js` (dice, dna, flask, chart, terminal, book, heart and more).
The brand mark is the **dice** icon on a silver tile with a 1 px black frame (the browser tab icon).

## Graphics
Open `marketing/post-templates.html` in a browser. It renders ready-to-screenshot 1080x1080 posts and 1080x1920 stories
in the brand style (use the browser's device toolbar or a full-page screenshot). Edit the text right in the file.

Best real content: screen recordings. Film the projector during a reveal (all the guys walking to their answers),
Moth Hunter's population shifting color, and a phone being used as a buzzer.
